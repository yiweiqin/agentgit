# 相关工作证据矩阵（第二版）

## 说明

本矩阵第一版（2026-09-14）只覆盖 6 篇文献，且以「主题邻近性」为主要判断依据。**第二版做了一次方法上的更换**：本轮检索发现，2026 年已出现多篇与本项目机制直接重叠的成体系工作，其中若干篇**占用了第一版所依赖的差异化位置**。因此本版不再只做邻近性罗列，而是按「与本项目哪一处主张竞争」重新组织，并单列一节**自伤性证据**（即对本项目不利、但必须正面处理的实验结果）。

本矩阵只证明文献身份、核对程度与主题边界。对论文具体方法和实验结论的引用，必须以核对级别为 L1 的条目为准；L2/L3 条目不得引用其算法细节或效果数字。

## 核对分级

| 级别 | 定义 | 可支持的表述 |
|---|---|---|
| **L1 全文已读** | 本地存有 PDF 或完整网页文本，可定位到页码或章节 | 可引用方法、数据、基线、效果数字 |
| **L2 摘要已读** | 只读了公开摘要 | 只能引用摘要层面的研究对象与边界 |
| **L3 元数据已核对** | 只核对了题名、年份、venue、DOI | 只能证明文献存在与主题邻近 |

> 本轮共核对 **50+ 条**文献，其中 L1 为 11 条，L2 为 30+ 条，L3 为若干条。**L2/L3 条目的具体效果数字一律不得引用**，这是第一版就写明的纪律，本版不得放松。

## 九、自伤性证据（必须正面处理）

以下三条对本项目不利，但正是审稿人会用来质疑的地方。**不得回避，必须写进正文或预注册。**

### 9.1 静态预写准入在实测中退化为串行

*Claim Plane* 确认性研究（arXiv 2608.00947，L1）报告：静态准入把 **96.7% 的执行序列化**（含 93.3% 的干净用例），clean specificity 仅 6.7%；其配对通过率（50.0%）与「总是串行」臂完全相同；动态准入更选择性（干净用例仅 13.3% 被序列化），但 46/90 次执行因未声明作用域 fail-closed，配对通过率掉回 22.2%。

**含义**：本项目 H5（非退化并行性）不是防御性的额外要求，而是**唯一的差异化位置**。若治理 agent 的收益同样主要来自阻塞，则本项目的贡献与已有工作无法区分。该文自身承认「未能满足类似串行的质量 + 并行吞吐这一更广目标」，因此本项目应把它作为「已知开放问题」引用，而非把它当作已解决问题。

### 9.2 指定协调者没有可观测收益

*When Agents Coordinate*（arXiv 2608.16801，L1）在 1902 次运行中发现：**指定一个 agent 作为 coordinator 不产生通信枢纽，也没有可靠的成功率提升**。

**含义**：这直接质疑「一个治理 agent 代行协调职责」这一制品形态的有效性。本项目的答辩不能停留在「需要一个全局视图」，必须给出机制层面的区分：已测的 coordinator 是**会话内消息协调者**，本项目主张的是**跨会话、以持久结构化账本为状态的外部协调者**。两者是否可区分，本身就是可检验的假设，建议纳入预注册。

### 9.3 冲突报告在规格恢复面前没有增量收益

*The Specification Gap*（arXiv 2603.24284，L1）的因子恢复实验显示：仅恢复完整规格即可把两 agent 集成准确率恢复到单 agent 上限（89%），而**提供冲突报告没有可测量的额外收益**。

**含义**：这对「检测器 + 报告」类贡献是直接打击。本项目必须回答：当任务/规格本身是充分的恢复工具时，语义实体检测与风险报告的边际贡献在哪里？可辩护的回答方向是：本项目的目标是**在规格信息已经存在但未落入仓库**的条件下（即 §1.1 主场景），恢复的是**绑定**而非**规格内容**。这一区别需要成为 H6 与检测评估的前提条件，而不是事后解释。
