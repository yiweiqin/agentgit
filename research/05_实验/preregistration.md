## 1. 假设与判据（照抄总纲，不重新定义）

**研究问题与假设**（总纲 §5）：

- `RQ1`/`H1`（失配存在性）：\(\lambda/R\) 越过临界值后，积压增长率显著上升。
- `RQ2`/`H2`（失配→混乱）：不可解释度随累积积压单调上升。
- `RQ3`/`H3`（质而非量，**理论赌注**）：控制 \(\lambda/R\) 后，agent 驱动变更的不可解释度显著高于人类变更。
- `RQ4`/`H4`（AI 治理有效）：治理 agent 在固定 \(\lambda\) 下显著抬高有效 \(R\)。
- `RQ4`/`H5`（非退化并行性，**方法学防线**）：`H4` 的收益在控制有效并行度 \(P\) 后仍然存在。

**Kill criteria**（总纲 §7）：`K1` 不存在临界比；`K2` 不可解释度与积压无关；`K3` `P5` 为真（agent 变更只是"量"的问题）；`K4` `H4` 收益完全来自阻塞（`H5` 假）；`K5` 双人一致性不达标；`K6` 多开发者多 agent 数据无法获得。

> 总纲原文："**K3 与 K4 是本方案的两条命门**……必须在预注册里写明。" 本节即为该要求的落实。

## 4. `E2` 检测准确率：冻结指标与下限

**真值由构造给出**，任务包含四类结构：真碰撞（共享实体）、**语义重复**（同意图不同措辞，最难）、独立对照（**不该报警**）、隐藏依赖。

**冻结下限**（未达则触发对应迭代器，**不得**调低下限来通过）：

| 指标 | 下限 | 未达则 |
|---|---|---|
| recall（真碰撞 + 语义重复） | ≥ 0.60 | `I3`：实体/意图匹配信号不足 |
| precision（真碰撞） | ≥ 0.80 | `I4`：调阈值与置信门槛 |
| **误拒率**（独立对照被拦） | ≤ 0.05 | `I4`：同上。**这是 H9 的硬约束，不可放宽** |

**硬约束（总纲一致）**：争用重叠**本身永远不能**作为协调失败的证据。`E2` 的 precision 只按"构造真值"判定，不按"重叠"判定。

## 5. `E3` 主实验：臂、主指标、样本量、停止规则

### 5.1 臂（必须同任务包、同种子）

| 臂 | 记录 | 干预 | 用途 |
|---|---|---|---|
| `A0-baseline` | 关 | 无 | 裸基线 |
| `A1-instrument` | 开 | 无 | **安慰剂**：分离观测者效应 |
| `A2-empty-plugin` | 关 | 无（装但惰性） | 控"加载插件"本身 |
| `A3-advisory` | 开 | `agent/pre-step` 注入上下文 | 纯协调（抬 \(R\)） |
| `A4-gated` | 开 | `tools/pre-execute` deny/ask | 准入门控（压 \(\lambda\)） |

`A3`/`A4` 的"记录"与"干预"两个开关**必须独立**（已在 `src/config.ts` 里以结构字段锁定，`overrideArm` 拒绝改动结构性字段）。`A4` 是**已知会触发 K4 的形状**，保留它是为了**测出触发点**，不是为了当推荐配置。

### 5.2 主指标（**唯一**，冻结）

**重复落地率（redundant landing rate）**：

> 被 ≥2 个 task 各自实装、且事后被判定为同一意图的落地实现数 ÷ 该臂落地功能总数。

选它作为唯一主指标，理由：它是**跨会话失明**这一机制的**直接**产物，而非下游代理量。其余两个浪费分量入副指标并做多重比较校正。

### 5.3 副指标（全部必须报告，即使不利）

- 返工/回滚率（复用 `repair_or_revert_history` 路径级证据）
- 测试破坏（被后续任务修复的测试失败数）
- \(B(t)\) 的 AUC、结束未调和数、落地吞吐
- **有效并行度 \(P\)**：时间加权平均在飞胶囊数（`parallelism.mean`）
- **并行时长占比**（`parallelism.parallelFraction`）：窗口内 ≥2 胶囊同时在飞的时间占比

> `P` 与 `parallelFraction` **必须与主结果同时出现**。只报 \(P\) 会漏掉"均值不变但突发并行被压掉"的情形。两者都是 `E-K4` 的分母。

### 5.4 样本量：**两阶段冻结**（本文件只冻结规则，不冻结数字）

在拿到 `E1` 的方差估计之前写死一个 `N` 是编造。因此冻结的是**规则**：

1. `E1` 完成后，用其主指标方差做功效分析：目标 power `0.80`，双侧 \(\alpha=0.05\)，最小有意义差异 MID = **主指标相对下降 30%**；
2. 由该分析得到的 `N` 以**带时间戳的修订**写入本文件 §5.4，**在 `E3` 首轮采集之前**；
3. 下限与上限：`8 ≤ N ≤ 40` 每臂。若规则给出的 `N > 40`，则**先减小任务包规模**（而非放弃对照臂）；
4. **修订只能改 `N`，不能改主指标、不能改 §5.6 的 kill 触发、不能改 §5.2 的主指标定义。**

### 5.5 停止规则

- **期中分析**：在计划轮次的 50% 与 75% 处各一次，名义显著性按 O'Brien–Fleming 型消耗函数收紧（50% 处 \(\alpha'=0.005\)，75% 处 \(\alpha'=0.014\)，末次 \(\alpha'=0.045\)）；
- **无效停止**：若期中分析中主指标效应的 95% CI 完全落在 MID 之内（即排除了有意义的改善），停止该臂；
- **安全停止**：若 `E-K4` 在期中即触发（见 §5.6），立即停止该臂并降级为纯 advisory；
- 停止决定与依据必须写入 `results/`，包括"因为无效而停"的记录。

### 5.6 `E-K4` 触发（本文新增，防"你只是限流"）

在 `A3`/`A4` 相对 `A1` 的对比中，若满足任一：

- `parallelism.mean` 相对下降 **> 15%**，或
- `parallelism.parallelFraction` 相对下降 **> 25%**

则判为**收益来自阻塞**，触发总纲 `K4`：该配置**不得**称为"AI 治理"，只可称为限流，并须在论文中如此表述。

> 阈值 15%/25% 是**采数前**写下的判断，不是事后拟合。选这两个数的理由：`A1` 与 `A0` 之间的抖动（观测者效应）预计远小于 15%，因此该阈值能把"治理"与"限流"分开；若 `E1` 显示抖动更大，**必须通过 §8 的修订流程改阈值并说明**，不得静默放宽。

### 5.7 分析

- 主指标在**对数尺度**上分析（比率量），报效应量与其 95% CI，不只报 p 值；
- 轮次为随机效应，臂为固定效应（混合效应模型）；
- 所有轮次的**方差**必须报告，不得只报均值；
- 盲评：给"可重建性"打分的评审**不知道臂身份**；
- 判定规则、材料、培训、分歧裁决与 \(\kappa/\alpha/AC1\) 一并报告（`K5` 的落实）。

## 7. 效度控制（冻结）

- 种子固定 + `llm-replay` 用于确定性臂；真实 API 用于生态效度；
- **隔离**：每臂/每轮独立 git worktree 与独立 `DSH_HOME`，全部在远程机沙箱目录内，**绝不触及用户真实仓库**；
- **版本锁定**：DSH 提交、Node/pnpm 版本、模型快照、任务包哈希、插件提交、分析脚本哈希，全部记入 `results/` 的 `provenance.json`；
- API key 只写入远程机 `~/.dsh` 与环境变量，**绝不入仓**；
- **观测者效应**：任何治理效应都必须与 `A1-instrument`（记录开、治理关）对比，而非与 `A0` 对比。

### 9.0 两个新阻塞（本轮新增，均为外部依赖）

1. **模型凭据**：headless 会话已能启动、建会话、写持久日志、进入 turn 1，唯一失败点是
   `MISSING_CREDENTIAL: llm-deepseek: no API key for provider route "deepseek-official"`。
   **关于 `llm-replay` 的重要修正**：它不是可凭空合成的桩模型，而是**回放录制好的 `session.jsonl` 夹具**
   （其 README：「Recording is therefore "run the real agent once and harvest the `.jsonl`" — this plugin does not record」）。
   ⇒ §5 的"用 `llm-replay` 做确定性臂"仍成立，但**前置条件是用真实 API 先录一次夹具**；
   确定性臂因此分两阶段：**录制（烧 API，每场景≥1 次）→ 回放（零成本、可复现 N 轮）**。
   E3 的"N 轮"必须在**同一份夹具**上做，否则比较的不是同一条模型轨迹。
2. **机器规格**：见 `results/provision/machine-assessment.md`。该机器是 Docker 容器
   （非计划要求的 KVM VM）、全部 namespace 被封（bwrap 不可用）、约 1 个有效核、2 GiB 内存上限。
   E1/E3 在此机器上**存在效度威胁而不仅是慢**：并发是自变量，1 个核会把会话强制串行，
   使 \(B(t)\) 不增长，从而把"现象不存在"（K1/K2）误判为真。
