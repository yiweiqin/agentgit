# Gate A Pilot：ACCD 标签校准集

本目录是用于检查标注规范和数据格式的最小校准集，不是顶会论文中的真实经验数据。

## 数据性质

- `scenarios.jsonl` 中的标签为 `synthetic_oracle`，由场景构造条件直接决定；
- 它们用于测试标签本体是否能区分文本冲突、语义冲突、重复、无归属产物和集成债务；
- 不能用这些样本计算真实的标注者一致性，也不能据此宣称 ISCC 检测有效；
- 正式 Gate A 必须用相同格式替换为真实项目回放或可验证的受控 agent 轨迹，并由独立标注者重新标注。

## 文件

```text
scenarios.jsonl       # 8 个最小场景及构造真值
annotation_template.json  # 去除真值后的标注表模板
```

## 场景设计原则

1. 每个场景至少包含一个基线、两个并行任务和两个变更集；
2. 正例和负例成对出现，避免把“同文件”误当作“语义冲突”；
3. 结果性标签（如 integration debt）必须包含返工或验证成本证据；
4. 任务目标、验收条件和实体范围分开记录；
5. 所有真值都附带 `evidence_type`，便于日后替换为测试、审查或历史提交证据。

## 建议使用方式

先删除 `oracle` 字段，将每条记录提供给两名标注者；检查他们是否能仅依据 `pre_view` 和 `result_view` 重建相同标签。该步骤只验证手册的可理解性。完成真实数据采集后，再计算各标签的一致性并进入 Gate B。
